# 风机偏航对中台

现场技师登记机组编号与偏航误差（度），**报送时必须从「在役」桨叶出厂号名册中点选一个出厂号**；后台 worker 用数据库行锁认领待处理记录，按 ±1.5° 阈值写入「合格」或「偏航超差」。前端为 Lit 组件 + Vite，接口为 Quart + Hypercorn。

## 桨叶出厂号名册规则

- 顶栏「桨叶名册」专页：**在役 / 退役两张表**，每行附该号绑定过的报送单示例；下方为名册变更与绑定履历。
- 仅现场技师（technician）可维护名册：支持**单号登记**与**号段登记**（前缀 + 起止 + 补零位宽），以及对单个在役号**退役**；观察者（observer）只能读名册、不能改册（接口同样返回 403）。
- 报送强校验（在数据库事务内完成，不只靠页面）：
  - 必须点选在役出厂号，**空选 / 未登记 / 已退役一律整单退回（400）**；
  - 库内 `SELECT ... FOR UPDATE` 行锁 + 触发器双重校验，封堵「校验通过后、落库前被退役」的竞态，以及绕过页面的旁路写口；
  - 出厂号**绑定后随单冻结**：任何 UPDATE 改绑/清空均被触发器拒绝；桨叶退役只影响新报送，**旧单永远保留原号**；
  - 退役不可逆（不能恢复在役）。
- 名册变更（登记/退役）与绑定履历通过触发器与业务在**同一事务一次落齐**（`blade_serial_events` 表）。

## 验收

1. 种子数据：机组 W01 误差 0.4° 结论「合格」（绑 BLADE-001）；机组 W07 误差 3.2° 结论「偏航超差」（绑已退役的 BLADE-006，旧单保留原号）。名册含 BLADE-001~005 在役、BLADE-006/099 退役。
2. technician 提交新记录时须点选在役桨叶号，提交后列表先显示「待处理」，数秒内 worker 处理后变为对应结论，桨叶号随单显示且冻结。
3. observer 可查看列表与名册（无维护表单，直打维护接口返回 403）。
4. 名册页：单号 / 号段（如前缀 `BLADE-`、10~12、位宽 3 → BLADE-010/011/012）登记后进入在役表并写入履历；退役后进入退役表。
5. 报送必拒场景：不选号（空选）、填未登记号、选已退役号（如 BLADE-099）——均整单退回并提示。
6. 冻结场景：用在役号（如 BLADE-004）报送成功 → 将其退役 → 再用同号报送被拒；此前那张旧单仍显示 BLADE-004。
7. 旁路写口：即使绕过页面直写数据库，未登记/退役号 INSERT、旧单改绑 UPDATE 均被触发器拒绝。

## 技术栈

- 后端：Quart、psycopg、`worker.py`（`FOR UPDATE SKIP LOCKED`）、Hypercorn
- 前端：Lit、TypeScript、Vite；生产镜像内 nginx 反代 `/api`
- 镜像源：DaoCloud 基础镜像、清华 PyPI、npmmirror npm
